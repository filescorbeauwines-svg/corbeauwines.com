Filosofia

Negociamos o começo do próximo negócio

Uma operação se fecha em semanas. Um programa se sustenta anos. Os dois se assinam igual; só um constrói algo.

Nenhum acordo é desenhado para maximizar a primeira venda, mas para que o cliente queira voltar. É mais exigente: pede um preço que financie o serviço, uma margem que funcione para ele e capacidade de cumprir no ano difícil.

Escrevemos essa forma de pensar em um livro. Não é material de marketing: é o critério com o qual se decide aqui dentro.
